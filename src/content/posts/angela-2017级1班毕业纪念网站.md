# 🎓 Angela. - 2017级1班毕业纪念网站

> 这片星空等待着你们的驻扎，每个人都可以成为其中一颗星，和他人绑定关系联系在一起。

## 📖 项目简介

一个承载青春回忆的毕业纪念网站，以星空为意象，将每位同学比作一颗星，通过连线展示彼此之间的关系纽带。留言墙等待着每一位同学去填充属于自己的故事。

## 🌟 核心功能

### 1. 星空关系图 (Starfield)

![图片描述](/AngelaPage/images/a026e63a8128d330c7fd2187ca374358.png)

每位同学都是一颗星，连线构成我们共同的星座。

**功能特点：**

- 互动式星空可视化界面
- 鼠标悬停查看同学详细信息
- 支持资料/关系管理
- 滚动切换星空图与学生列表视图

**界面预览：**

- 深蓝色星空主题背景
- 悬浮信息框展示同学资料
- 关系连线可视化

### 2. 同学留言墙 (Guestbook)

写下你的祝福或回忆，记录我们共同的青春。

**功能特点：**

![图片描述](/AngelaPage/images/f147560b990a9aa641fd8cb5621b7693.png)

- 留言发布（昵称、配文、内容、图片）
- 匿名发布选项
- 管理员审核机制
- 留言卡片式展示

**界面预览：**

- 清新米白色主题
- 表单输入区 + 留言展示区
- 图片上传支持

### 3. 博客发布工具

强大的后台管理工具，支持 Markdown 语法。

**功能特点：**

- 标题、描述、分类、标签编辑
- 封面图设置
- Markdown 正文编辑
- 图片/视频上传与管理
- 本地仓库图片选择

## 📂 网站结构

```
2017级1班 · Angela.
├── Home        # 首页
├── Class       # 班级介绍

```
